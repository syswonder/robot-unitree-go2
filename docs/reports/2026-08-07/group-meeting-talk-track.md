# Robonix-Go2 组会口头汇报稿（2026-08-07）

这周主要完成了面壁 MiniCPM-RobotTrack 在 Unitree Go2 EDU 上的视觉跟随部署，并把它正式接入 Robonix。RobotTrack 被封装成 Robonix Primitive `go2_robottrack`，完成了 codegen、lifecycle 和 manifest 配置，因此可以随 Robonix 全栈统一初始化、启动和停止，而不是用独立模型脚本直接控制机器狗。

运行时由 D435i 获取画面、RTX 工作站执行模型推理，结果进入 Robonix provider，再经过速度源选择和原有的平滑、guard、Go2 单控制器底盘链执行。原来的 generation 1 地图、中文语音导航、Nav2 全栈以及停止、看门狗和遥控器接管行为都完整保留。

目前前进和左右转向跟随都已通过实机测试。先完成了 45 秒正式测试，随后完成了 75 秒复测；最新测试累计行走约 12.36 米，前进速度最高 0.5 米每秒，转向速度最高 0.3 弧度每秒，运动期间一直保持经典步态 2010。

网页可以同时查看原始相机画面和模型预测结果。最新测试中 D435i 的 375 帧画面均持续更新，结束后约 0.61 秒进入明确停止状态。本次测试已经结束，机器人由现场人员手动趴下，相关服务也已关闭，录包和日志均已保留。

当前结果证明了受控场地里的持续视觉跟随，但还不能等同于复杂动态环境完整通过。目标丢失、遮挡、多人、光照变化以及独立 LiDAR 障碍保护仍需要专项验证。

下一步会根据演示需求补充这些场景测试，并整理一键启动与结果材料；已通过的 generation 1 导航功能保持可直接复用，不重复此前完成的实机阶段。

代码已整理为独立的 RobotTrack 跟随 Draft PR #6；它基于 Go2 完整全栈 PR #1，Navigation PR #9 也已补充所需的可选原始速度输出，普通 Nav2 默认路径不变。
